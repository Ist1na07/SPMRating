# 评估与模型取舍

[English](evaluation.md) · [使用说明](../README.zh-CN.md)

## 排序数字衡量什么

Spearman 排序相关系数衡量模型排序与标签排序的一致程度。在给定集合中，数值越高，排序越接近。相同数值使用平均名次。

开发评估的加权汇总为：

\[
0.5\rho_{7K}+\frac{5}{18}\rho_{4K}+\frac{2}{9}\rho_{\mathrm{jack}}.
\]

长条与6键集合分别报告。这些集合在开发中被反复使用；新的集合有助于了解模型在其他环境中的表现。可供程序读取的结果见 [benchmark.json](benchmark.json)。

| 集合 | 计分谱面数 | 汇总权重 |
|---|---:|---:|
| 7键 | 393 | 0.5 |
| 4键 | 741 | 5/18 |
| 连打为主 | 292 | 2/9 |
| 长条为主 | 40 | 单列 |
| 6键扩展 | 2343 | 单列 |

两支候选均计算了全部3809张支持输入。另有一张6键输入包含同刻同键但尾部冲突的对象，按当前输入约定排除。

## 结果

| 指标 | v1.1.1参考 | 完整模型 | 精简模型 |
|---|---:|---:|---:|
| 加权排序相关系数 | 0.981346 | **0.988334** | 0.988271 |
| 7键排序相关系数 | 0.979041 | **0.988976** | 0.988759 |
| 4键排序相关系数 | 0.985726 | 0.988330 | **0.988452** |
| 连打集合排序相关系数 | 0.981059 | 0.986895 | **0.986950** |
| 长条集合排序相关系数 | 0.883076 | **0.904663** | 0.899101 |
| 局部12段排序相关系数 | 0.514097 | **0.866219** | **0.866219** |
| 7键标签误差界之和以外的错序对 | 293 | 103 | **99** |
| 6键排序相关系数 | — | **0.957222** | 0.956659 |

v1.1.1参考使用统一的开发比较流程与集合；一些旧版本汇总使用不同的谱面子集，统计范围有所区别。

局部面板由12个选定的7键段落组成，它们已经包含在7键集合中，其中9段涉及长条。这一面板展示了开发范围内的局部行为；楼梯叠与切键仍需要更广泛的专门对照。

7键标签附有标注者估计的最大误差。当两张谱的标签差距大于双方误差之和，而模型将其顺序颠倒时，计入误差界外错序指标。符合间隔要求的58614对中，完整与精简模型分别错序103对和99对。这一指标补充整体排序统计，聚焦于标签分离较清楚的谱面对。

## 如何理解两支模型

完整模型的加权与长条相关系数略高；精简模型的误差界外错序较少，持续时间费用结构也稍简单。两支局部相关系数相同，个别谱面的分数仍可不同。

两支都保留了较多历史特征。文件包含291个配置字段和一个手指角色幅度，其中若干字段对应固定设置或关闭分支。精简模型的持续时间组件关闭后，有四个连续值退出有效作用。各键数输出对齐还包含一个比例与一个指数，它们保持该键数内的排序。

角色费用幅度的0.1下限表达了受P/Q游玩对照支持的建模选择。早先版本将两组控制谱评为同分，一名玩家在120和180BPM都认为Q明显更难。这些控制已用于设计。完成后的完整模型将Q评为比P高约2.9%，精简模型约高3.3%。更多玩家和预留控制有助于了解这一差别的幅度及适用范围。

## 核验与运行速度

公开运行代码从完成的评分器中整理为独立包。每支模型的全部3809张支持谱面的整谱输出，都与已存档的完成模型比较；每支另有45个整谱与局部案例检查公共接口。附带的小型测试覆盖生成控制谱、局部约定、时间延拓和重复对象处理。

耗时取决于谱面长度、局部窗口和时间精度。首次调用包含编译。原始时间为整数时使用原生路径；大量不同小数时刻可能需要多次相位评分。两支共用大部分计算，因此精简后的结构在当前实现中带来的速度差别较小。

值得继续评估的方向包括新谱面集合、时间和物量配平的楼梯叠与切键游玩对照，以及手指占用分布不同的局部段落。这些证据可以同时指导进一步精简与动作模型调整。
