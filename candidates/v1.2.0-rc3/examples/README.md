# P/Q playtest controls

[简体中文](README.zh-CN.md)

These generated 7-key charts compare two arrangements of sustained finger occupation, with matched timing and note counts. The included click tracks allow playing them at 120 and 180 beats per minute. Copy this directory into osu!'s Songs folder to try them, or pass the `.osu` files directly to the scorer.

One playtest found Q clearly harder at both speeds. The comparison informed the finger-role component, so further evaluation benefits from fresh control arrangements and additional players. The detailed and compact models currently place Q about 2.9% and 3.3% above P.
