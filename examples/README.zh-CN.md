# P/Q 游玩控制谱

[English](README.md)

这些生成的 7 键谱面对比两种持续占用手指的安排，时间和音符数量配平，并附带 120 与 180 BPM 的节拍音频。可将本目录复制到 osu! 的 Songs 文件夹中体验，也可直接将 `.osu` 文件交给评分器。

一次游玩对照在两个速度下都认为 Q 明显更难，这一比较直接启发了手指角色组件的设计，后续亦适合使用新的对照安排与更多玩家持续验证。在 v1.3.0 下，**`detail`** 模型将 Q 评为比 P 高约 **4.5%**（120 BPM）与 **7.7%**（180 BPM），**`compact`** 模型分别高约 **1.1%** 与 **1.7%**。
